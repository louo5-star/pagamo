## 🌟 核心特色

1. **一隊 3 人 · 支援雙隊對決與四隊爭霸**
   - **雙隊對決模式**：2 支隊伍同場競技（共 6 人，3人/隊），落點於地圖南北對稱島嶼，距離中央核心城堡完全等距。
   - **四隊爭霸模式**：4 支隊伍同場角逐（共 12 人，3人/隊），落點於對稱之四向外圍島嶼。
   - **選手自由選隊入座**：每個人進入遊戲後，可輸入選手姓名，並挑選代表隊伍之「席位 1（隊長）」、「席位 2」、「席位 3」。
2. **初始總積分為 0 分**
   - 參賽隊伍進駐初始起始島嶼作為安全大本營，**一開始總積分嚴格為 0 分**。
   - 所有分數皆由選手於 20 分鐘賽事中答對題目、開拓新領地與攻佔特殊地形逐步累積。
3. **官方決賽能量與計分系統**
   - **總能量 1000 點**：同隊 3 人共享團隊能量池。
   - **答對題目**：消耗 **6 點能量**，獲得 **+7 分**，成功攻佔目標領地（若攻下特殊地形額外加分）。
   - **答錯題目**：消耗 **15 點能量**，攻打失敗（土地保持原狀），並即時顯示正確族語與語法解析供選手訂正。
   - **特殊地形加分**：
     - 👑 **城堡 (Castle)**：**100 分** / 座
     - 🏯 **碉堡 (Bunker)**：**80 分** / 座
     - 🎯 **砲台 (Cannon)**：**50 分** / 座
     - 🌊 **新拓領地 (Territory)**：**3 分** / 塊
   - **團隊總積分官方採計公式**：
     $$\text{團隊總積分} = \text{特殊地形積分加總} + \sum [(\text{答對數} \times 7) + (\text{新佔領地數} \times 3)]$$
4. **《中排灣語句型練習》43 頁全篇提取 300 題題庫**
   - 提取自官方族語教材 250 組真實對話，依教育部與原住民族語言認證規範生成 300 題隨機題庫：
     - **語意理解 (130題)**：排灣語句子 $\to$ 中文意思選擇
     - **族語表達 (90題)**：中文生活情境 $\to$ 正確排灣語說法選擇
     - **情境對話 (50題)**：說話者 A 問答 $\to$ 說話者 B 最適當回應
     - **核心詞彙 (30題)**：高頻生活單字理解（桌子 `cukui`、書本 `laqulj`、雨 `qudjalj`、老師 `sinsi`、星星 `vitjuqan`、早餐 `enama` 等）
5. **純前端無後端架構 · 支援 GitHub Pages 部署**
   - 採用純 HTML5 Canvas + Web Audio API + 原生 JavaScript，無需資料庫即可於 GitHub Pages 免費靜態託管。

## 🚀 如何部署至 GitHub Pages

本專案採零依賴純靜態架構，上傳至 GitHub 後即可開啟即時線上遊玩：

1. **建立 GitHub 倉庫並推送程式碼**：
   ```bash
   git init
   git add .
   git commit -m "feat: PaGamO 城堡爭奪戰 總決賽 (中排灣語版)"
   git branch -M main
   git remote add origin https://github.com/<您的使用者名稱>/<倉庫名稱>.git
   git push -u origin main
   ```
2. **開啟 GitHub Pages**：
   - 進入 GitHub 倉庫頁面，點擊上方 **Settings** $\to$ 左側 **Pages**。
   - 在 **Build and deployment** 下的 **Source** 選擇 `Deploy from a branch`。
   - **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
   - 等待約 1 分鐘，即可透過 `https://<您的使用者名稱>.github.io/<倉庫名稱>/` 開啟遊戲！

## 🕹️ 多人連線與遊玩方式

### 方式 A：單機多分頁即時連線（電腦教室/展示最推薦）
* 遊戲內建 HTML5 `BroadcastChannel` 雙向同步機制。
* 在同一台電腦打開 6 個（雙隊模式）或 12 個（四隊模式）瀏覽器分頁。
* 每個分頁輸入不同姓名，點選各自的隊伍席位（如：分頁 1 入座「望嘉小尖兵·席位1」，分頁 2 入座「族夢團·席位1」…）。
* 任一分頁點擊開拓、答對題或扣除能量，**所有其他分頁皆會即時同步翻色、扣能與更新排行榜**！

### 方式 B：區域網路多台裝置連線（平板、Chromebook、手機）
若要在教室內讓學生使用個別的平板或筆電連線：
1. 在教師端或主機端啟動內建的 Python 同步伺服器：
   ```bash
   python server.py
   ```
2. 終端機會顯示您的區域網路連線網址（例如 `http://192.168.1.100:8080`）。
3. 學生使用同一 Wi-Fi 下的設備輸入該網址，即可各自選隊入座連線作戰！

## 📜 競賽規則與賽事流程

1. **備戰階段**：選手透過「👤 選隊入座」輸入姓名並選擇隊伍與席位。
2. **比賽開始**：裁判點擊頂部「▶️ 開始計時」，20 分鐘木紋沙漏開始倒數。
3. **開拓領地**：在地圖上點擊與己方現有領地相鄰之邊界土地，系統隨機抽取中排灣語考題。
4. **搶佔核心**：中央 7 座核心城堡（每座 100 分）、外圍 12 座碉堡（每座 80 分）與 24 座砲台（每座 50 分）為決勝關鍵要塞。
5. **立即結算**：計時歸零或點擊「🏆 立即結算」，系統自動結算所有隊伍之官方總分，並可一鍵匯出 CSV 成績單！
