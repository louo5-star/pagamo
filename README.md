## 🌟 核心特色與競賽規格

### 1. ⚡ 隊員獨立能量制（每人各自 500 點能量）
- **不再是全隊共用 1000 點**：每位參賽選手（隊員 1、隊員 2、隊員 3）各自擁有獨立的 **500 點個人能量池**。
- **答對消耗 6 點個人能量**（個人能量 $500 \to 494$），團隊總積分 $+7$ 分，成功攻佔目標領地。
- **答錯消耗 15 點個人能量**（個人能量 $500 \to 485$），攻佔失敗，保留領地原貌。
- **隊友互不干擾**：隊員 A 答題只扣除隊員 A 的個人能量，隊友 B、C 的個人能量完全不受影響，各隊員可平行思考出題攻地。
- **能量歸零限制**：當選手個人能量低於 6 點時無法繼續攻地，但隊友若有剩餘能量可繼續拓展領地。
- **全場雲端即時同步**：所有選手的個人剩餘能量即時呈現在 HUD、席位卡片與決賽成績榜中。

### 2. 📱 電腦、平板與手機通盤自適應排版與現代捲軸設計（Chrome / Edge / Safari 全平台支援）
- **🎨 現代輕巧木質細捲軸（Modern Slender Scrollbars）**：
  - 專為 Windows Chrome、Edge、macOS、Android 與 iOS WebKit 打造之古典實木配色超薄捲軸（寬度僅 7px，帶有細緻圓角與木質陰影，滾動滑順），徹底取代傳統 Windows 瀏覽器粗糙生硬的 17px 灰色矩形捲軸。
  - 支援標準 `scrollbar-width: thin; scrollbar-color: #c8ab78 ...` 與 WebKit 雙規格，於題庫總覽、結算成績單、隊伍選席、設定與長解析內容中一體成型。
- **📱 手機直向與橫向（Portrait & Landscape）深度體驗優化**：
  - **極限高度橫向模式（Low-height Landscape $\le 520\text{px}$）**：針對手機打橫（360px~414px 高度），答題視窗自動切換為 **2x2 雙欄選項網格**（A/B 在上、C/D 在下），縮減題目邊距，確保題目與 4 個選項完全置於一屏之內，**零滑動直接點選作答**！
  - **視窗與彈窗定錨鎖定（Pinned Modal Architecture）**：所有彈窗（選隊席位、答題、題庫、競賽設定）頂部標題列與底部「確認/套用」按鈕嚴格釘選（Flex Pinned），中間內容區獨立平滑滑動，在任何超小手機螢幕上絕不會發生「確認按鈕被擠出螢幕外」之窘境。
  - **頂部導航欄單行防溢橫移（Single-Row No-Wrap Nav）**：在手機小螢幕上鎖定為 40px 高度並支援橫向輕觸滑動，絕不垂直換行擠壓地圖遊戲畫面。
  - **即時戰況排行榜極簡收合**：手機或直向平板載入時預設處於收合狀態（呈現小巧精緻的金色標籤 `⭐ 戰況 ◀`），將 100% 畫面完整交給六角格地圖與操作；點擊標籤隨時展開查看兩隊比分。
- **🖐️ 平板專屬雙手指自由縮放（Two-Finger Pinch-to-Zoom）**：
  - 選手在 iPad、Chromebook 或 Android 平板上，**隨時可用兩隻手指在畫面上張開（放大）或捏合（縮小）**，縮放視角範圍支援 $0.4\times \sim 2.5\times$。
  - 核心採用 `touch-action: none` 與高精度焦點鎖定算法，**手指間的地圖中心點絕不漂移**，且單指拖曳平移與雙指捏合縮放平滑無縫切換，徹底消除瀏覽器預設滾動干擾！
- **🔍 懸浮觸控縮放輔助按鈕（Floating Zoom Controls）**：
  - 畫面右側提供四組圓形金色實木觸控鈕，平板與手機選手亦可單指輕觸：
    - `➕`：畫面放大（+20%）
    - `➖`：畫面縮小（-20%）
    - `🎯`：相機立即飛回本人起始基地島嶼
    - `🌐`：全景鳥瞰（以自適應倍率一覽外圍六島與中央高分城堡）
- **觸控目標尺寸規範（Touch Targets $\ge 38\text{px}$）**：
  - 所有按鈕、席位選單與選項嚴格遵循觸控規範，防止手指誤觸。

    - 島嶼 1（東北）：【族夢團】隊員 1 · 東北海域基地 `[8, -8]` (7塊領地)
    - 島嶼 2（東南）：【望嘉小尖兵】隊員 2 · 東南海域基地 `[8, 0]` (7塊領地)
    - 島嶼 3（南）：【族夢團】隊員 2 · 南方海域基地 `[0, 8]` (7塊領地)
    - 島嶼 4（西南）：【望嘉小尖兵】隊員 3 · 西南海域基地 `[-8, 8]` (7塊領地)
    - 島嶼 5（西北）：【族夢團】隊員 3 · 西北海域基地 `[-8, 0]` (7塊領地)

  - **登入自動聚焦**：選手選擇席位或重新進入遊戲時，相機**自動平移並精準置中於本人的起始島嶼**（不再全員擠在同個視野）。

  - **HUD 一鍵定位按鈕**：左下角選手資訊面板隨時提供「`🎯 我的基地`」按鈕，無論地圖瀏覽至何處，一按立即飛回自己的領地。
  - **領地旗幟番號**：所有領地旗幟均標註佔領選手席位（1, 2, 3），開疆闢土一目了然！

### 4. 🎮 雙遊玩模式：🏆 比賽模式（預設） vs 📖 練習模式（隨時自由作答）
- **🏆 比賽模式 (Tournament Mode) · 官方正式規格（預設模式）**：
  - 進入遊戲預設即為「比賽模式」。
  - **開賽前防搶答保護**：在比賽未開始或暫停時，點擊地塊會受到保護並彈出提醒「⚠️ 比賽尚未開始，請由老師/裁判按下右上角『▶️ 開始比賽』！」，不會誤開題目、扣除能量或提前偷跑。
  - **按下「▶️ 開始比賽」後解鎖**：全體選手倒數計時啟動（預設 20 分鐘），按鈕變更為「⏸️ 暫停計時」，此時方可點選相鄰領地作答排灣族語題目、扣除個人能量、攻佔土地並累積積分！
- **📖 練習模式 (Practice Mode) · 課堂練習隨時作答**：
  - 選手或教師可透過頂部導航欄 `模式: 📖 練習模式`、選隊席位彈窗或設定彈窗一鍵切換。
  - **隨時作答無阻礙**：無須等待裁判按下開始比賽，學生隨時點擊相鄰可開拓地塊即可立即作答練習！
  - **沙漏顯示為「自由練習」**：不限時，無倒數歸零強制結算的壓力。
  - **⚡ 500 點能量自動補滿機制**：練習模式下每次答對消耗 6 點、答錯消耗 15 點，但當個人能量用盡時，系統會自動補滿至 500 點，確保學生能無限制連續刷題練習中排灣語句型！
  - **跨裝置即時同步**：教師或選手切換模式時，同房號的多台平板與電腦即時同步切換。

### 5. 🌐 跨裝置雲端即時同步（MQTT over WebSocket 零延遲連線）
- **時間、比分、個人能量、領地全場即時同步（<50ms）**。
- **競賽區域選項機制（1-5 區，預設第 1 區）**：提供直覺式選項下拉選單與按鈕快速切換「第 1 區」至「第 5 區」，不同分組或班級選擇相同區域即可跨裝置連線同場即時對戰，亦可透過網址參數指定（例如 `?room=2` 或 `?room=room2`）。
- **雙 Broker 備援**：整合 EMQX 與 HiveMQ 公共 WebSocket Broker，無需任何後端伺服器即可在 GitHub Pages 上實現跨網域即時對戰。

  - **情境對話 (50題)**：說話者 A 題目為純中排灣語句型，4 個選項亦為純排灣語對話回應，**絕無族語與中文同時顯示之洩題現象**！選手作答完畢後，系統於【族語解析】中完整呈現雙語對話與中文釋義，寓教於樂。
  - **核心詞彙 (30題)**：排灣語核心單字與句型必備詞彙測驗。

## 🚀 部署至 GitHub Pages

本專案為純靜態前端架構，拖曳上傳即可線上運作：

1. 開啟 GitHub 倉庫：[https://github.com/louo5-star/pagamo](https://github.com/louo5-star/pagamo)
2. 點選 **Add file ➔ Upload files**。
3. 將 `pagamo_github_upload` 資料夾中所有檔案拖曳上傳並 **Commit changes**。
4. 在 **Settings ➔ Pages** 確認 Source 為 `Deploy from a branch` (main / root)。
5. 約 1 分鐘後即可在 [https://louo5-star.github.io/pagamo/](https://louo5-star.github.io/pagamo/) 開始連線對戰！

## 📱 比賽操作指南

1. **開啟網址**：各台平板、手機或電腦打開網頁。
2. **選擇區域**：上方導航欄或彈窗選擇競賽區域（第 1 區 ~ 第 5 區，同區域自動連線同場）。
3. **選擇賽制與隊名**：
   - 點選「👤 選隊」➔ 選擇賽制模式（1對1、2對2、雙隊、四隊）。
   - 在「出戰隊伍選擇」自由挑選出戰隊伍（預設順序 1~6 隊，重複自動對調）。
4. **選手入座**：
   - 各選手點選席位卡片中的「席位加入」（每位選手各自擁有獨立 500 點個人能量）。
   - 老師或投影大螢幕點選「🎙️ 裁判 / 大螢幕觀戰席」。
5. **開賽發令**：裁判點擊「**▶️ 開始比賽**」，全場倒數計時、個人能量與即時計分同步啟動！
   - 亦可切換為「**📖 練習模式**」，隨時自由作答練習族語，能量自動補充！
