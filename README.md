## 🌟 核心特色與競賽規格

### 1. ⚡ 隊員獨立能量制（每人各自 500 點能量）
- **不再是全隊共用 1000 點**：每位參賽選手（隊員 1、隊員 2、隊員 3）各自擁有獨立的 **500 點個人能量池**。
- **答對消耗 6 點個人能量**（個人能量 $500 \to 494$），團隊總積分 $+7$ 分，成功攻佔目標領地。
- **答錯消耗 15 點個人能量**（個人能量 $500 \to 485$），攻佔失敗，保留領地原貌。
- **隊友互不干擾**：隊員 A 答題只扣除隊員 A 的個人能量，隊友 B、C 的個人能量完全不受影響，各隊員可平行思考出題攻地。
- **能量歸零限制**：當選手個人能量低於 6 點時無法繼續攻地，但隊友若有剩餘能量可繼續拓展領地。
- **全場雲端即時同步**：所有選手的個人剩餘能量即時呈現在 HUD、席位卡片與決賽成績榜中。

---

### 2. 📱 電腦與平板雙平台流暢排版（文字完全不遮蔽）
- **頂部導航欄彈性自適應（No Text Clipping）**：
  - 電腦大螢幕（1440px+）與平板（768px~1024px）自動調整間距與換行結構，所有操作按鈕（開始比賽、選隊、定位、題庫、音效、全螢幕、設定、結算）皆完整展示，絕不溢出或被邊界裁切。
- **即時戰況排行榜「收合 ▶ / 展開 ◀」機制**：
  - 平板學生點擊右上角排行榜的「**收合 ▶**」按鈕，即可將面板最小化為小巧的金黃色圖示徽章，**將 100% 的螢幕面積完整釋放給六角格地圖**，大幅提升平板觸控點擊與攻佔的流暢度！
  - 隨時點擊「**展開 ◀**」即可重新展開查看兩隊即時比分與各隊員剩餘能量。
- **答題視窗（Question Modal）與排灣族語排版優化**：
  - 支援觸控優化（選項按鈕高度 $\ge 48\text{px}$，符合 iPad 觸控規範）。
  - 題目支援自動換行與滾動檢視，排灣族語長句與族語解析絕不超出版面。
- **隊伍席位卡片響應式網格（Auto-fit Grid）**：
  - 平板直向與橫向自動適應為清晰的 1 或 2 欄寬度，3 個席位按鈕空間充足，完整顯示「席位 1 · 🟢本人 · ⚡500」。
- **畫面下方乾淨俐落**：遵守「畫面下面不必有文字說明」要求，無跑馬燈字幕干擾，地圖沉浸感最佳。

### 3. 🏝️ 同隊隊員分佔不同島 · 鄰近島嶼絕非隊友（交錯基地對抗制）
- **雙隊對決模式（2隊 · 6人同場）**：
  - 外圍 6 座島嶼環狀交錯（A ➔ B ➔ A ➔ B ➔ A ➔ B）：
    - 島嶼 0（北）：【望嘉小尖兵】隊員 1 · 北方海域基地 `[0, -8]` (7塊領地)
    - 島嶼 1（東北）：【族夢團】隊員 1 · 東北海域基地 `[8, -8]` (7塊領地)
    - 島嶼 2（東南）：【望嘉小尖兵】隊員 2 · 東南海域基地 `[8, 0]` (7塊領地)
    - 島嶼 3（南）：【族夢團】隊員 2 · 南方海域基地 `[0, 8]` (7塊領地)
    - 島嶼 4（西南）：【望嘉小尖兵】隊員 3 · 西南海域基地 `[-8, 8]` (7塊領地)
    - 島嶼 5（西北）：【族夢團】隊員 3 · 西北海域基地 `[-8, 0]` (7塊領地)
  - **每位隊員分佔獨立海域島嶼**：左右鄰島 **100% 全為敵隊**，兼顧競技公平性與四方合圍攻防策略！
  - **登入自動聚焦**：選手選擇席位或重新進入遊戲時，相機**自動平移並精準置中於本人的起始島嶼**（不再全員擠在同個視野）。
  - **專屬基地銘牌與金色光環**：地圖上清晰標示本人基地 `⭐ 我的基地 (隊員 X · 7塊)` 並帶有金色呼吸邊界光環；隊友基地標示為 `🤝 隊友基地`；敵隊標示為 `⚔️ 敵方基地`。
  - **HUD 一鍵定位按鈕**：左下角選手資訊面板隨時提供「`🎯 我的基地`」按鈕，無論地圖瀏覽至何處，一按立即飛回自己的領地。
  - **領地旗幟番號**：所有領地旗幟均標註佔領選手席位（1, 2, 3），開疆闢土一目了然！

### 4. 🌐 跨裝置雲端即時同步（MQTT over WebSocket 零延遲連線）
- **時間、比分、個人能量、領地全場即時同步（<50ms）**。
- **競賽房間機制（預設 `wangjia2026`）**：點擊導航欄 `[換房]` 即可自訂房號，亦可透過網址參數直接指定（例如 `?room=class701`）。
- **雙 Broker 備援**：整合 EMQX 與 HiveMQ 公共 WebSocket Broker，無需任何後端伺服器即可在 GitHub Pages 上實現跨網域即時對戰。

## 🚀 部署至 GitHub Pages

本專案為純靜態前端架構，拖曳上傳即可線上運作：

1. 開啟 GitHub 倉庫：[https://github.com/louo5-star/pagamo](https://github.com/louo5-star/pagamo)
2. 點選 **Add file ➔ Upload files**。
3. 將 `pagamo_github_upload` 資料夾中所有檔案拖曳上傳並 **Commit changes**。
4. 在 **Settings ➔ Pages** 確認 Source 為 `Deploy from a branch` (main / root)。
5. 約 1 分鐘後即可在 [https://louo5-star.github.io/pagamo/](https://louo5-star.github.io/pagamo/) 開始連線對戰！
